# Android captures (re-themed app)

Raw 1080x2400 captures from a release build on the Medium_Phone emulator (API 36.1), 100 generated test photos (`.maestro` style, June 2025), light (Cashmere) and dark (Espresso).

- Not store-ready: Discover shows locked dumps (free tier), paywall shows "Plans couldn't load" (no store offline).
- Taken with the CLIP native module switched off: the emulator CPU (Apple Silicon) crashes with SIGILL in `libLiteRt.so`. So no Tidy, no selfie/face results. Capture those on a real device.
