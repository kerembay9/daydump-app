## Description
カメラロールには、次のフォトダンプがもう入っています。PicDumpは日々、週、旅行のベストショットを見つけ、それぞれ4〜10枚を選んで、投稿できる形に並べます。

すべてスマートフォンの中で動きます。写真が端末の外に出ることはありません。アカウント不要、広告なし、トラッキングなし。

ダンプを見つける
• 自分の写真から作られるおすすめのダンプ。
• 日・週・月・年のまとめは、いつでも無料で開けます。
• 写真を言葉で説明して検索。お使いの言語で。

自分らしく仕上げる
• 写真の追加・入れ替え、テンポの確認、レイアウトとフレームの選択。
• ドラッグとピンチで各スライドをトリミング。
• フィルム風ルック、粒子、フェード、枠。

ワンタップで投稿
• スライドをPicDumpアルバムに保存して、InstagramやTikTokを開く、または共有メニューを使用。
• 下書きと投稿済みのダンプはライブラリに保存。再利用して新しいダンプを作れます。

整理する
• Tidyがスクリーンショット、レシート、ほぼ同じ写真を見つけ、数回のタップで整理。元に戻す・復元は常に無料です。

プライバシー重視の設計
• 写真のインデックス、提案、検索は端末内で作られます。
• 「センシティブな写真を隠す」で、身分証、カード、書類をダンプに入れません。
